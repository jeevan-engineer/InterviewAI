# InterviewIQ

> An AI-powered interview preparation platform that helps students practice technical interviews using personalized AI-generated questions, voice interviews, and detailed feedback.

## 🚀 Vision

InterviewIQ is being built as a production-ready SaaS application to simulate real technical interviews and help users improve over time.

## ✨ Planned Features

- User Authentication (Email & Google)
- Resume Upload (PDF)
- AI Resume Analysis
- AI-Generated Interview Questions
- Voice-Based Interview Practice
- AI Evaluation & Feedback
- Progress Tracking Dashboard
- Recruiter Dashboard
